# Инструкция пользователя

Приложение для учёта компьютерного оборудования колледжа. Работает в терминале,
данные хранит в файле `data/inventory.json`. Интерфейс — текстовое меню с номерами
пунктов: введите цифру и нажмите Enter.

## Что нужно для работы

- Python 3.11 или новее.
- Свободная папка с проектом (репозиторий).
- Docker не обязателен: он нужен только для запуска в контейнере.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Для обычной работы достаточно установить зависимости; pytest нужен только для тестов.

## Запуск

```bash
python main.py
```

На экране появится меню:

```
=== Учёт инвентаря ===
1. Показать оборудование
2. Добавить оборудование
3. Найти оборудование
4. Изменить оборудование
5. Удалить оборудование
6. Отбор по кабинету и состоянию
0. Выход
```

Выход из программы — пункт `0`. Если терминал завис, нажмите `Ctrl+C`: программа
завершится без ошибок и без потери уже сохранённых данных.

## 1. Показать оборудование

Выводит все записи и их количество. Формат строки:

```
INV-0001 | ПК | Системный блок Lenovo ThinkCentre | каб. 204 | исправно
```

## 2. Добавить оборудование

Программа по очереди спрашивает поля. Если номер не ввести и сразу нажать Enter,
подставится следующий свободный номер (например `INV-0009`).

| Поле | Правила заполнения |
|---|---|
| Инвентарный номер | Формат `INV-0001`: буквы `INV-`, дефис, затем цифры. Номер не должен повторяться. Регистр букв не важен: `inv-0005` сохранится как `INV-0005`. |
| Тип | Одно из: ПК, Монитор, Принтер, Ноутбук, Сканер, Прочее. |
| Наименование | Любой текст, обязательно хотя бы одна буква. |
| Кабинет | Только цифры, например `204`. |
| Состояние | Одно из: исправно, требует ремонта, списано. |
| Дата поступления | Свободный текст, например `12.03.2026`. |
| Ответственный | Фамилия и инициалы, например `Иванов И.И.`. |

Если поле заполнено неверно, запись не создаётся, а программа объясняет причину:
`Ошибка: Номер должен быть в формате INV-0001 (буквы INV-, затем цифры).`

## 3. Найти оборудование

Сначала выберите способ поиска:

- `1` — по инвентарному номеру: выводится одна карточка или сообщение «Не найдено».
- `2` — по кабинету: выводится список всего оборудования кабинета.

Номер можно вводить в любом регистре и с пробелами по краям.

## 4. Изменить оборудование

1. Введите инвентарный номер записи.
2. Введите новый кабинет. Если менять не нужно — просто нажмите Enter.
3. Введите новое состояние. Если менять не нужно — нажмите Enter.

Изменения сразу записываются в файл. Проверить их можно повторным поиском.

## 5. Удалить оборудование

1. Введите номер записи.
2. Подтвердите удаление словом `да`.

Любой другой ответ отменяет удаление, запись остаётся на месте.

## 6. Отбор по кабинету и состоянию

Пункт нужен, чтобы получить список, например, всего оборудования на ремонт.

1. Введите кабинет или нажмите Enter, чтобы не ограничивать по кабинету.
2. Выберите состояние цифрой `1`, `2`, `3` или нажмите Enter, чтобы не ограничивать.

Можно задать один признак или оба сразу. Если ничего не задано, программа попросит
указать хотя бы один признак.

## Где хранятся данные

Все записи лежат в `data/inventory.json`. Файл обновляется после каждого добавления,
изменения и удаления, поэтому закрывать программу можно в любой момент.

Копию данных удобно делать простым копированием этого файла.

## Что означают сообщения программы

| Сообщение | Что произошло | Что делать |
|---|---|---|
| «Файл данных не найден. Он будет создан при первом сохранении.» | Первый запуск или файл удалён. | Работать как обычно: файл появится после первой записи. |
| «Файл inventory.json пуст.» | Файл обнулился. | Добавить записи заново или восстановить файл из копии. |
| «Файл inventory.json повреждён. Копия сохранена как inventory.json.corrupt-…» | Файл не читается. | Взять данные из копии, исправить их вручную и заменить рабочий файл. |
| «В файле inventory.json пропущено некорректных записей: N.» | В файле есть элементы не того вида. | Проверить файл, лишние элементы удалить. |
| «Не удалось сохранить данные в inventory.json.» | Файл защищён от записи или диск недоступен. | Снять защиту с файла или освободить место и повторить операцию. |
| «Запись не найдена.» | Введён номер, которого нет в списке. | Проверить номер в пункте 1. |
| «Номер INV-0001 уже есть.» | Попытка добавить повторный номер. | Указать другой номер. |

## Известные ограничения

- Поиск по кабинету сравнивает номер целиком: `20` не найдёт `204`.
- Нет экспорта в Excel и печати отчётов.
- Нет пароля и разделения прав: любой, кто запускает программу, может изменить данные.
- Одновременная работа двух копий программы с одним файлом не поддерживается.
- Dockerfile подготовлен, но сборка контейнера на учебном компьютере не проверялась.
