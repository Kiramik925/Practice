# Система учёта инвентаря компьютерных классов

Консольное приложение на Python для учёта компьютерного оборудования в колледже.
Проблема, которую решает проект: в колледже теряется информация об оборудовании —
непонятно, что где стоит, в каком состоянии и кто за него отвечает.

## Текущее состояние (Спринт 1)

- Реализовано меню и пункт **«Показать оборудование»** на демонстрационных данных.
- Остальные пункты (добавить / найти / изменить / удалить) — заглушки, появятся в Спринтах 2–3.
- Данные хранятся в `data/inventory.json` (JSON).

## Требования

- Python 3.11 или новее
- pytest (для запуска тестов)

## Установка

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Команды меню

1. Показать оборудование — работает (Спринт 1).
2. Добавить оборудование — Спринт 2.
3. Найти оборудование — Спринт 3.
4. Изменить оборудование — Спринт 3.
5. Удалить оборудование — Спринт 3.
0. Выход.

## Тесты

```bash
python -m pytest
```

## Структура проекта

- `main.py` — меню и точка входа.
- `inventory.py` — модель записи и операции с инвентарём.
- `storage.py` — работа с JSON-файлом.
- `data/inventory.json` — демонстрационные данные.
- `tests/test_inventory.py` — автотесты.
- `USER_STORIES.md` — требования (User Stories).

## Ограничения (Спринт 1)

- Реализован только просмотр; запись в файл и полный CRUD — в следующих спринтах.
- Поиск, изменение и удаление пока не работают.
